# v3.0.0 — qo'lda tekshiruv (egasi)

1. `YangiAlifbo.Setup.exe` ni ishga tushiring (UAC — «Да») → soat yonida ko'k «Ö» belgisi chiqadi.
2. **Telegram Desktop**: `o'zbek tilida shahar va bog' haqida` deb yozing → `özbek tilida şahar va boğ haqida`.
3. **Chrome** (masalan Google qidiruvi): `choy` + bo'sh joy → `çoy`.
4. **Word 2007**: `Toshkent shahri` → `Toşkent şahri`; Ctrl+Z ishlaydi.
5. Noto'g'ri almashsa (masalan inglizcha so'z) — darhol **Backspace** → so'z qaytadi; yana yozsangiz tegilmaydi.
6. **Pause** → belgi kulrang, almashtirish yo'q; yana Pause → yoqiladi.
7. Brauzerda biror saytga kirish: login va parol maydonlari o'zgarmasligini tekshiring.
8. Kompyuterni qayta yoqing → «Ö» belgisi o'zi chiqadi.
9. O'chirish: `YangiAlifbo.Setup.exe /uninstall` → belgi yo'qoladi.
